# Credit Card Fraud Detection Using Machine Learning

## 📖 Problem Statement
Credit card fraud is a major issue in digital payment systems. Fraudulent transactions are rare, making detection challenging.  
The goal is to detect fraud accurately while minimizing false alarms.

## 🎯 Objective
- Detect fraudulent transactions.  
- Handle highly imbalanced data.  
- Identify suspicious transactions in real time.  
- Deploy as a web application for easy use.

## 📊 Dataset
**Source:** Kaggle  
Contains transaction-level data including amount, time, and fraud labels.

## ⚙️ Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  
- Scikit-learn  
- Streamlit  

## 🧠 Machine Learning Algorithms Used
- Logistic Regression  
- Decision Tree  
- Random Forest  
- XGBoost  

## 📈 Results
- The model achieved high accuracy in detecting fraud.  
- Real-time predictions via Streamlit web app.
